# Commitment Poker

Página estática para apresentar a metodologia de Planning Poker por compromisso e mediana.

## Publicação na Vercel

1. Importe este repositório na Vercel.
2. Mantenha o preset **Other**.
3. Não preencha *Build Command* nem *Output Directory*.
4. Clique em **Deploy**.

A Vercel servirá `index.html` diretamente. Não há dependências para instalar.

## Estrutura

- `index.html`: página responsiva, com explicação da metodologia e simulador da regra de mediana.
- `vercel.json`: configuração leve de URLs e cabeçalhos.
